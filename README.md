# LeetCode Solutions

Мои решения задач с [LeetCode](https://leetcode.com/) на C# — с юнит-тестами (xUnit) поверх обычных сабмишенов.

## Решения

Каждая задача — отдельная папка `NNNN_НазваниеЗадачи`, где `NNNN` — номер задачи на LeetCode.

| #    | Задача                                                                    | Сложность | Темы                | Код                                     |
|------|----------------------------------------------------------------------------|-----------|---------------------|------------------------------------------|
| 0002 | [Add Two Numbers](https://leetcode.com/problems/add-two-numbers/)          | Medium    | Principal, Linked List, Math, Recursion   | [C#](./LeetCodeLib/0002_AddTwoNumbers)   |
| 0174 | [Dungeon Game](https://leetcode.com/problems/dungeon-game/description/)          | Hard    | Array, Dynamic Programming, Matrix   | [C#](./LeetCodeLib/_0174_DungeonGame)   |

## Запуск тестов

```bash
dotnet test
```
